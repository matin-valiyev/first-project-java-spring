First Project Java Spring

A simple web application built with Java and Spring Boot that demonstrates the basics of web controllers and template rendering.

 Features
- Spring MVC: Uses `@Controller` to handle web requests.
- Request Parameters: Captures data from the URL using `@RequestParam`.
- Thymeleaf: Renders dynamic content into HTML templates.

 Tech Stack
- Java
- Spring Boot
- Thymeleaf
- Maven

 Project Structure
- `HelloController.java`: Manages the `/greeting` route.
- `greetings.html`: The view template located in `src/main/resources/templates`.
- `pom.xml`: Project configuration and dependencies.
